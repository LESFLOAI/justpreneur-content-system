# JustPreneur Content Calendar

## Fixed cadence

Two draft cycles a day, every day: 10:00 AM and 9:00 PM local time, run by the cloud routine via `/justpreneur-draft`. Posting is a separate, manual step (`/justpreneur-finish`) — there's no fixed "post time," a draft posts whenever it's approved.

## Slots

The Scheduler agent appends rows here as slots open, fill, and post. Status is one of: open / in progress / ready to post / posted.
